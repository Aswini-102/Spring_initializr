# Spring_initializr

Spring Initializr is a web-based tool provided by the Spring team that helps developers quickly generate a ready-to-use Spring Boot project

 🔖Go to the Website
   https://start.spring.io

🔖 Fill in Project Metadata

🔖 Select Dependencies
   You can search and select Spring Boot starters or dependencies. 

🔖 Generate Project
   Once you configure everything, click "Generate". A .zip file will download.

🔖 Import into IDE
    Unzip the folder

    Open it using IntelliJ IDEA, Eclipse, VS Code, etc.

    It’s pre-configured with:

    pom.xml 

    Source directories: src/main/java and src/main/resources

🔖 Run the Application
    Run the main class (usually named DemoApplication.java) directly from your IDE or terminal
